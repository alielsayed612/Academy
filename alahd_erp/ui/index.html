📊 لوحة القيادة التنفيذية

نظرة شاملة ومباشرة على الأداء المالي، التحصيل حسب تاريخ الدفع، وفترات الدراسة حسب تاريخ البداية الفعلي

⚖️ القاعدة المحاسبية والتربوية المعتمدة: 💳 تاريخ الدفع (Payment Date) يُعتمد حصريًا لتتبع السداد والتقارير المالية، بينما 📅 تاريخ البداية الفعلي (Actual Start Date) يُعتمد حصريًا لحساب مدة الاشتراك ومواعيد الحصص دون دمجهما أبدًا.

👋 مرحبًا بك في أكاديمية يوم جديد

قاعدة البيانات فارغة حاليًا وجاهزة لإدخال بيانات أكاديميتك. يمكنك البدء بإحدى الطرق التالية:

📈 مقارنة الأداء الشهري للمعلمات

⏱️ تحليل توقيت السداد وفترات الدراسة الفعلية

📈 الإحصائيات العامة والتقارير التحليلية

مؤشرات شاملة للطالبات، التحصيل (النقدي والاستحقاق)، المعلمات، الباقات، الحضور، الحفظ، والمدرسة الإيمانية

🔔 مركز التنبيهات الرقابية الذكية

متابعة استباقية للاشتراكات، المتأخرات، مواعيد الدراسة، الحصص غير المعوضة، وسلامة النسخ الاحتياطية مع انتقال مباشر

👩‍🎓 سجل الطالبات والاشتراكات الشهرية

إدخال وتعديل مستقل لكل من تاريخ الدفع الفعلي (Payment Date) وتاريخ بدء الدراسة الفعلي (Actual Start Date)

🪪 الملف الشامل للطالبة 360°

عرض تفصيلي مستقل للسجل المالي (تاريخ الدفع والإيصالات) والسجل الدراسي (تاريخ البداية الفعلي ومدة الاشتراك)

💳 التحصيل المالي وتقارير تواريخ الدفع والبدء

اعتماد الإيصالات كمصدر وحيد لحالة السداد مع مقارنة تاريخ الدفع (Payment Date) بتاريخ البداية الفعلي (Actual Start Date)

🧾 تسجيل إيصال دفعة / سداد اشتراك (حسب تاريخ الدفع)

⚡ محاكاة وحاسبة فصل تاريخ الدفع عن تاريخ البداية الفعلي

📋 كشف التحصيل التفصيلي ومقارنة تاريخ الدفع بتاريخ البداية الفعلي

🧾 سجل إيصالات الدفعات والأقساط (مع طباعة إيصال مستقل)

💰 رواتب المعلمات والمقارنة الشهرية

حساب آلي دقيق بقاعدة التقريب القياسية (Round Half Up) مع سجل صرف المستحقات

📊 الجدول المقارن لرواتب المعلمات

🧭 تجهيز ومراجعة استحقاق الرواتب الشهرية (إعداد آلي بدون صرف تلقائي)

💵 تسجيل صرف راتب لمعلمة

📜 سجل الدفعات المصروفة للمعلمات

🏦 الخزينة والمحاسبة العامة

متابعة التدفقات النقدية الداخلة والخارجة (أساس نقدي) ومقارنتها بصافي الاستحقاق التشغيلي (أساس استحقاق)

➕ إضافة قيد محاسبي (إيراد إضافي / مصروف تشغيلي)

🗓️ توليد خطة حصص ذكية (مبنية على تاريخ البداية الفعلي)

📋 سجل الحصص والمواعيد والتعويض التلقائي

👩‍🏫 أقسام وإدارة المعلمات والباقات

إدارة قائمة المعلمات (إضافة، تعديل الاسم والنسبة، إيقاف مؤقت أو إعادة تفعيل)، وباقات الاشتراك الموحدة

➕ إضافة أو تحديث معلمة

📦 إدارة باقات وأنظمة الاشتراك الموحدة (مصدر موحد لجميع القوائم)

📥 استيراد البيانات من Excel / CSV

استيراد آمن مع معاينة مسبقة (Dry-Run)، مطابقة تلقائية للأعمدة العربية، وفصل تام بين تاريخ الدفع وتاريخ البداية الفعلي

1️⃣ اختيار نوع البيانات ورفع الملف

2️⃣ مطابقة الأعمدة وملخص الفحص

⚠️ تم تغيير الملف أو خيارات الاستيراد بعد آخر معاينة؛ يرجى الضغط على «تحليل ومعاينة الملف قبل الحفظ» لتحديث المعاينة قبل الاعتماد.

📤 مركز التصدير والتقارير الثابتة

تصدير تقارير إكسيل (.xlsx)، صفحات HTML ثابتة للقراءة فقط والطباعة، أو نسخ قواعد البيانات (.json)

🌐 تصدير صفحة تقرير HTML ثابتة للقراءة فقط (قابلة للفتح والطباعة على أي جهاز بدون إنترنت)

📦 1. المصنف الشامل الكامل (Full ERP)

يضم سجل الطالبات (بتاريخ الدفع وتاريخ البداية الفعلي)، ورقة تتبع التواريخ، رواتب المعلمات المقارنة، الملخص، والأقسام.

👩‍🎓 2. سجل الطالبات وتواريخ الدفع والبدء

يصدّر جدول الطالبات الشهري مع ورقة مراجعة تواريخ الدفع المالية وتواريخ البداية الفعلية.

💰 3. إحصائية ورواتب المعلمات الشهرية

يصدّر جدول المقارنة وإجمالي الرواتب وصافي الأكاديمية وسجل الصرف.

🏦 4. المحاسبة العامة وإيصالات الأقساط

يصدّر الخزينة، القيود المحاسبية، الإيصالات، وتقرير تواريخ الدفع والبدء.

🗓️ 5. الحلقات والمواعيد والحفظ والمدرسة الإيمانية

يصدّر جداول الحصص والحضور وسجل تسميع ومراجعة القرآن الكريم والمدرسة الإيمانية.

🔄 6. نسخ حالة المنظومة (JSON) وتصدير جدول الطالبات (CSV)

ملف JSON يمثل نسخة كاملة لجميع بيانات المنظومة قابلة للاستعادة، بينما ملف CSV يصدّر جدول الطالبات للشهر المحدد فقط (قابل لإعادة الاستيراد في قسم الطالبات).
